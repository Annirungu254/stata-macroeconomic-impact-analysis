# 📈 Stata Econometric & Panel Data Analysis Project

An empirical econometric study examining macroeconomic indicators, evaluating economic shocks or trends, and analyzing market relationships using Stata.

## 📂 Repository Contents

* `Project_2_guide.pdf`: The official project questions, guidelines, and assignment instructions.
* `project_2.dta`: The raw dataset used for the empirical analysis.
* `PROJECT-2 STATA DO FILE COMMANDS.do`: The complete Stata do-file containing all data cleaning, transformation, and estimation commands.
* `PROJECT-2 DOCUMENT.docx`: The final analytical report detailing the methodology, empirical results, and economic interpretations.

## 🛠️ Tech Stack & Methods

* **Software:** Stata
* **Techniques Applied:**
  * Data cleaning, variable generation, and transformation.
  * Summary statistics and exploratory data analysis.
  * Econometric modeling and regression analysis.
  * Hypothesis testing and interpretation of coefficients.

## 🚀 How to Run the Code

1. Download or clone this repository to your local computer.
2. Open Stata and load the `PROJECT-2 STATA DO FILE COMMANDS.do` script.
3. Update the working directory path at the top of the do-file using `cd "path_to_your_folder"` to point to where you saved the files.
4. Run the script to replicate the data cleaning steps and regression outputs seamlessly.
